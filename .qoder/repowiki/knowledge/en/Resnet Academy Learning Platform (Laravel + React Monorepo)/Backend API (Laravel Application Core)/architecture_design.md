The module follows Laravel's standard MVC-plus pattern: `routes/api.php` and `routes/auth.php` declare endpoints that dispatch to `app/Http/Controllers`, which validate input via `Requests/*` DTOs, enforce authorization through `Policies/*`, delegate business logic to domain-scoped `Services/*` folders (Assessment, Enrolment, Communication, Content, etc.), persist state via Eloquent `Models/*`, and serialize responses with `Resources/*`. Cross-cutting concerns are isolated in `Jobs/*` (queued work), `Mail/*` and `Notifications/*` (outbound messaging), `Console/Commands/*` (scheduled tasks), and `Enums/*` (shared value objects). The `config/` directory supplies environment-driven wiring for Sanctum auth, CORS, database, queue, cache, logging, mail, and filesystems consumed by all layers.
