The repository is a single Laravel 12 project that serves as both the backend API and the host for the frontend SPA. The `backend_api` module provides HTTP routes, controllers, services, models, policies, jobs, and Sanctum-authenticated APIs; the `frontend_app` module is a React + Vite SPA whose build output is served alongside Blade templates in `views_and_assets`. Both share the `database_schema` migrations/factories/seeders so the frontend and backend operate against one consistent data model. The `tests` module mirrors the app's domain layout to exercise both API endpoints and unit logic via Pest/PHPUnit, while `storage_runtime` holds uploaded files, compiled views, cache, sessions, and logs produced by all other modules at runtime. Cross-cutting concerns (auth via Sanctum, PDF generation via dompdf, email via Resend, S3 storage via Flysystem) are configured centrally in the Laravel framework bootstrap and consumed uniformly by backend services and any frontend-facing Blade views.
