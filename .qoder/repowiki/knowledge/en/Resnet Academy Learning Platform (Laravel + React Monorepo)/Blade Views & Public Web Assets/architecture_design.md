Two top-level directories form the module: `resources/views/` contains pure Blade templates organized by domain — `welcome.blade.php` is the default landing page, `certificates/pdf.blade.php` renders a styled certificate HTML intended to be converted to PDF via a backend renderer, and `emails/enrolment-confirmed.blade.php` is an HTML email template consuming Eloquent models (`$enrolment->student`, `$enrolment->course`). The `public/` directory is the web server document root; `index.php` boots the Laravel application via `bootstrap/app.php` and delegates every request through `$app->handleRequest(Request::capture())`, while `.htaccess` rewrites all non-file/non-directory requests to that front controller and forwards Authorization/XSRF headers. Static files (`favicon.ico`, `robots.txt`) are served directly by the web server without touching PHP.
