Single-page application bootstrapped from `src/main.tsx` with React Router v8 defining all routes in `src/App.tsx`. The app is split into three layers: (1) shared UI primitives under `src/components/ui` (custom shadcn-style components plus Radix-based wrappers like Button, Modal, Select, Tooltip), (2) layout shell (`src/components/layout`) — `AppShell` renders a role-aware sidebar/topbar chrome via `PageHeaderProvider`, `ProtectedRoute` enforces route-level RBAC using roles passed from `useAuth`, and `PublicLayout` wraps landing pages; (3) feature modules under `src/features/<domain>` (auth, catalogue, learning, assessment, admin/*, communication, progress, profile, sections, etc.), each self-contained with its own page components, local hooks (`useXxx`), and an `api.ts` module that calls the backend via Axios. Cross-cutting concerns live in `src/lib/`: `auth/AuthContext` (React Query-backed auth state), `pageHeader/PageHeaderContext` (page title/search injection into the shell), plus utilities for audit logging, status badges, course sequencing, and YouTube embedding. Styling uses Tailwind CSS v4 with `@tailwindcss/vite`; build/dev tooling is Vite with TypeScript, ESLint + Prettier, Vitest for unit tests (jsdom, configured in `vite.config.ts`), and Playwright for e2e tests under `e2e/`.
